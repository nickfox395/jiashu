# 家书使用教程

家长在 Android 手机上用「家书」写消息，孩子在平板上用「中育云笔记」阅读和回复。两端使用同一个学生账号。

## 安装与登录

1. 在手机浏览器登录有权访问本仓库的 GitHub 账号，下载并打开 APK。此安装包适用于 Android 7.0 及以上的 ARM64 设备。[下载家书 0.3.10 ARM64（版本码 2014）](https://github.com/nickfox395/jiashu/releases/download/v0.3.10/jiashu-0.3.10-arm64-v8a-2014.apk)
2. 如果手机已有家书，直接打开 APK 尝试覆盖安装。若提示签名冲突，请保留旧版并联系提供安装包的人；卸载会清除本机记录。首次安装时，按系统提示允许当前浏览器或文件管理器安装此 APK。
3. 打开家书，输入学校代码、学生账号和密码，选择「爸爸」或「妈妈」作为署名。默认勾选「记住登录信息」，下次登录会自动填入学校、账号、密码和署名。取消勾选可清除记忆。若学校仅提供 HTTP，登录页会要求确认明文传输，请先阅读提示。
4. 登录后点聊天页右上角「同步」。首次同步成功后，孩子在平板云笔记的根目录中就能找到「家书」文件夹。

## 发出第一封家书

1. 在家书首页点「开启话题」，输入「周末安排」并创建。孩子会在云笔记里看到带署名的话题文件夹，例如「爸爸：周末安排」。
2. 进入话题，输入「周六想去哪里？」并点向上箭头发送。每条消息最多 60 字，会成为这个文件夹里的一份笔记。也可以直接在首页发送日常消息。
3. 消息下方出现「服务器已保存」表示服务器已经确认保存。孩子还需要在平板上同步，才能看到这份笔记。
4. 要在同一话题下另聊一件事，点「开分支」。目录卡片显示话题创建时间。重新打开家书或发完消息后，聊天窗口会定位到最下方。

## 孩子如何回复

1. 在平板打开「中育云笔记」，执行同步，依次进入「家书」和对应的话题文件夹。
2. 打开家长的笔记阅读。要回复，在**同一个文件夹里新建一份笔记**，写下回复，保存后同步。
3. 家长在手机上点「同步」，即可查看回复。孩子也可以直接在原笔记里续写并同步，家长会在对应话题看到「笔记有更新」。

## 接收来信提醒

打开家书右上角的设置，开启「后台接收与新消息提醒」，并允许 Android 通知。聊天页打开时约每 30 秒检查一次，后台接收开启后约每 3 分钟检查一次。点未读横幅可进入对应话题，点「本话题已读」可标记该话题。

如果暂时没收到回复，先确认孩子已在平板保存并同步，再在手机点「同步」，查看「最后成功同步」的时间。只有打开家书才能收到提醒时，检查手机的通知权限和后台省电限制。

## 修改笔记正文

聊天列表只显示消息文字。点笔记气泡即可打开正文。多页笔记用屏幕底部的箭头翻页，双指可缩放。首次同步后的新消息，只要署名与当前身份不同，就会显示红色星号。正文显示后，该条消息的星号会消失。

打开笔记后点右上角「修改」可编辑当前页。上方显示笔记标题，多页正文底部显示当前页/总页数。也可在已同步的笔记旁点「⋯」→「修改笔记正文」。家长和孩子的笔记都可以选；多页笔记先选择要改的页。用「画笔」写画，用「涂白」覆盖内容，或选「文字」后点页面确定插入位置。点「撤销」可撤回本次操作。

点「保存」会立即将所选页的修改存到手机，返回后即可查看或继续编辑。家书在后台同步这次修改；离线或正在同步时，先显示「已保存到本机，等待同步」。服务器确认后显示「已同步」。笔记保留原名和其他页面。如果提示笔记已被修改，先重新同步并打开最新页面，再编辑。

## 清理手机上的聊天记录

| 想做什么 | 操作和效果 |
| --- | --- |
| 删除一条消息 | 消息旁点「⋯」→「删除消息」。本机隐藏该消息及关联更新提醒，待发消息会取消发送，该笔记未同步的正文修改也会从本机清除。 |
| 清空所有话题里的消息 | 设置 →「清空聊天记录」→「清空」。清除当前账号在本机各话题中的消息和未读提醒，清除未同步的正文修改，取消待发消息，保留话题目录和草稿。之后仍可在原话题收信。 |
| 隐藏整个话题 | 目录卡片菜单 →「删除目录」。本机同时隐藏子目录和其中的消息，以后也不会提醒该目录中的新内容。 |

上述清理操作均保留云笔记原件。退出登录会结束当前会话。已勾选记住的信息会在登录页回填，本机聊天历史保留。

开发和接口细节见[中育平台后端接口说明](docs/中育平台后端接口说明.md)。
